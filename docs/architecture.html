HelloAgents Trip Planner Architecture

Tool-grounded PlannerContext → single Planner LLM → validated TripPlan JSON

Request path

  • • Vue form posts TripRequest to FastAPI
  • • /plan/stream emits one SSE event per graph node
  • • Result page renders budget, maps, days, weather
  • • Plan cached in sessionStorage; editable + exportable

Grounding & guarantees

  • • Facts come from Amap REST, never the LLM
  • • Pricing, rerank, validation are pure functions
  • • Nodes never raise: failures become rows
  • • User always gets a plan (deterministic fallback)

Optional modules

  • • RAG: Qdrant hybrid search → soft inspiration notes
  • • Critic: deterministic + gated LLM reflection loop
  • • Personalized planner: fine-tuned model for final step
  • • LangSmith tracing + experiment runner (eval/)
